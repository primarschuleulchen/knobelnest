# Werkstatt

Hier liegt alles, was zum Bauen und Prüfen des Knobelnests gebraucht wird. Das Portal selbst lädt nichts aus diesem Ordner.

- `originale/`: deine eigenen Werkzeuge, so wie du sie geschickt hast (Hausaufgabentafel, Klassen-Pinnwand, Tagesfolien, Otterteich, Atelier). Daraus entstehen die Knobelnest-Versionen.
- `einbau/`: kleine Programme, die deine Originale ins Knobelnest einbauen (Klassenliste, Speicher, Freigaben …). `alle_neu_bauen.py` baut alle neu und prüft sie.
- `test/`: Testseite mit Schein-Datenbank und Datenbank-Test. Es werden keine echten Daten verwendet.
- `sql/`: Abfragen, die du in Supabase ausführen kannst, um etwas nachzuschauen (sie ändern nichts).

Wichtig: Das Repository ist öffentlich. Hier kommen nie Namen oder Notizen von Kindern hinein.
